This repository contains an implementation of machine learning models to classify the presence of diabetic retinopathy using the Diabetic Retinopathy Debrecen dataset. The dataset features various clinical and visual attributes extracted from retinal images, such as quality assessment, microaneurysm counts, exudate measurements, and structural metrics like macula-optic disc distance and optic disc diameter.

Models Used
We implemented and compared the performance of the following machine learning models:

Logistic Regression: A baseline model to assess the linear relationship between features and the target variable.
Support Vector Machine (SVM): A robust classifier capable of handling non-linear decision boundaries using kernel functions.
Artificial Neural Network (ANN): A deep learning model for capturing complex patterns and relationships in the dataset.
The results provide insights into the effectiveness of these models for automated diabetic retinopathy screening.
